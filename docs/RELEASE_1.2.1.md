Empfohlenes Update: Family Access Manager 1.2.1 zuerst installieren, danach Light Manager 1.5.0, Shutter Manager 1.9.0 und Hausarbeiten 0.5.0. Home Assistant neu starten und Browser/App neu laden.

Urlaubsmodus ausschließlich zentral unter Family Access → Einstellungen. Lokale Schalter entfallen aus den Anwendungen; programmbezogene Urlaubspausen bleiben. Rollen- und Dashboardrechte sowie die Originalkomponenten aus HA UI Kit 1.6.0 bleiben erhalten.
