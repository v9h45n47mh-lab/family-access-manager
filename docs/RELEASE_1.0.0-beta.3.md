Family Access Manager **1.0.0-beta.3** ergänzt persönliche Dashboardnavigation.

- Rollenname nur einmal sichtbar; Umbenennen über das Stiftsymbol.
- Dashboards je Rolle mit Pfeilen sortieren und die Reihenfolge auf ausgewählte Benutzer übernehmen.
- Pro Administrator sichtbare Dashboards und Startseite wählen. Der volle Administratorzugriff bleibt bestehen.
- Technische Zugriffstests unter **Einstellungen → Diagnose**.
- Persönliche HA-Einstellungen bleiben bei der Reihenfolgeübernahme erhalten; fehlgeschlagene Übernahmen werden je Konto gemeldet und protokolliert.
- Oberfläche vollständig mit Originalkomponenten von **HA UI Kit 1.6.0**, ohne lokale CSS-Regeln.

Rollen, Freigaben und Benutzeraktivierungen werden übernommen. Nach dem Update HA neu starten und den Browser vollständig neu laden. Vorabversionen gegebenenfalls in HACS einblenden.

Prüfumfang und Ergebnisse: [Testnachweis](https://github.com/v9h45n47mh-lab/family-access-manager/blob/v1.0.0-beta.3/docs/TESTERGEBNISSE.md).
